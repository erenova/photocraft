## Why this task exists

This is the fork owner's main use of PhotoCraft: product images for their brand, generated by
AI as PNGs (an object on a plain or softly graded background, usually with no alpha). They take
the background off, clean the edges and export a transparent PNG, the way they do it today in
Photoshop and Photopea. If any step of that flow fails or behaves differently from Photoshop,
PhotoCraft is useless to them. Tasks 00 (Quick Selection) and 01 (Magic Wand) fix the selection
tools; this task proves the whole flow, step by step.

## Photoshop behaviour (the spec)

The flow in Photoshop 2026, with the three ways people take a background off:

1. **Open** the PNG (File › Open). An opaque PNG opens as one locked layer named *Background*;
   a PNG with alpha opens as *Layer 0*.
2. **Route A, Magic Wand** (what the owner does): Tolerance about 32, Contiguous on, Anti-alias
   on. Click a corner of the background; **Shift-click** the other corners and any background
   islands (gaps inside handles and so on). Optionally Select › Modify › Expand by 1 px.
   - On the locked *Background* layer, Delete doesn't make transparency: on Windows, Delete
     opens Edit › Fill (Content-Aware) and Backspace fills with the background colour
     (inferred from Photoshop's long-standing behaviour; check what `docs/ui-parity.md` and the
     existing tests already say before changing anything). To get transparency, first unlock
     it (click the lock in the Layers panel, or Layer › New › Layer from Background; it becomes
     *Layer 0*).
   - On a normal layer, **Delete clears the selection to transparency**.
3. **Route B, select the product**: Select › Subject, or Quick Selection (task 00), or the
   Object Selection tool. Then either Select › Inverse + Delete, or add a layer mask (Layers
   panel *Add layer mask* = Reveal Selection).
4. **Route C, one click**: Properties panel › Quick Actions › **Remove Background**. Converts
   *Background* to a normal layer and adds a layer mask hiding the background (task 03 covers
   its quality).
5. **Edge cleanup**: Select › Select and Mask… (Smooth, Feather, Contrast, Shift Edge, Refine
   Edge brush, **Decontaminate Colors**, Output To: Layer Mask / New Layer with Layer Mask);
   Layer › Matting › **Defringe…**, **Remove White Matte**, **Remove Black Matte** on a layer
   with transparency, to kill the light or dark halo left by the old background.
6. **Trim**: Image › Trim… › Based on *Transparent Pixels*, trim all four sides.
7. **Export**: File › Export › **Quick Export as PNG** (keeps transparency), or File › Export ›
   **Export As…** (PNG, *Transparency* checked, image size, which starts from the current
   document's size), or File › Save a Copy… as PNG.

Name a public source for any detail you rely on that isn't above (Adobe Help pages, the repo's
`docs/*-parity.md`), and mark anything undocumented as inferred.

## What PhotoCraft has (verify each; don't trust this list)

Command ids exist for: `select.magicWand`, `select.quick`, `select.subject`, `select.inverse`,
`select.modify.expand` / `contract`, `select.selectAndMask`, `edit.clear`, `edit.fill`,
`layer.removeBackground` (`crates/engine/src/cutout_cmds.rs`, also in the Properties panel's
Quick Actions, `props_layout.rs`), `layer.matting.defringe`, `layer.matting.removeWhiteMatte`,
`layer.matting.removeBlackMatte`, `image.trim`, `file.export.quickExportAsPng`,
`file.export.exportAs`. Check how *Background* is created on PNG import (`crates/io`) and what
Delete does on it.

## How to do it

1. **Test images, made in code** (clean-room, nothing downloaded): a 2048×2048 opaque RGB PNG of
   a product-like object (a rounded bottle or box with gradient shading, a highlight, anti-aliased
   edges and a soft contact shadow) on (a) near-white with a faint gradient and noise, (b) a flat
   colour, (c) a two-tone studio sweep; plus (d) the same with an alpha channel; plus one with a
   handle-shaped hole showing background through it. You know the true mask: use it to score.
2. **Script each route** (A, B, C) through the engine commands, from file open to PNG export and
   re-import. Score each result: mask IoU against the truth, mean alpha error on the edge band,
   halo (mean distance of edge-pixel colour from the product colour), time per step on the VM.
3. **Drive the UI** for the steps that live there (the Layers panel lock, Delete on
   *Background*, the Quick Actions button, Export As defaults) with the egui test harness, and
   take snapshots (AGENTS.md rule 6).
4. **Compare every step with the spec.** Small gaps (about an hour each): fix them here, with a
   test each. Bigger gaps: write `../pc-loop/prompts/tasks/NN-slug.md` from
   `../pc-loop/prompts/TASK_TEMPLATE.md` (next free numbers) and list them in your report for the
   orchestrator to add to the board. Put the whole table in `docs/gaps.md` too.

## Acceptance criteria

- [ ] A test per route (A, B, C) that runs open → select → remove → clean → trim → export →
      re-import on the synthetic images and asserts: transparent background, opaque product,
